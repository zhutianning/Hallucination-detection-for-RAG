# 幻觉检测指南：区分幻觉与其他错误类型

## ⚠️ 核心原则

**将"错误答案"等同于"幻觉"是不准确的。** 必须严格区分：

- **幻觉（Hallucination）**: 模型编造了**源文档中不存在**的信息
- **其他错误**: 基于正确信息但处理过程出错（检索失败、推理错误、计算错误等）

## 📊 错误类型分类矩阵

| 错误类型 | 定义 | 是否为幻觉 | 检测方法 |
|----------|------|------------|----------|
| **信息编造** | 编造源文档中不存在的数值/名称/事件 | ✅ **是幻觉** | 在源文档中全文搜索，确认不存在 |
| **虚构事件** | 编造未披露的并购/诉讼/分红等 | ✅ **是幻觉** | 搜索关键词，确认未提及 |
| **虚假因果关系** | 编造不存在的因果联系 | ✅ **是幻觉** | 检查管理层讨论章节，确认未提及 |
| **检索不完整** | 未检索到所有相关信息，导致答案不完整 | ❌ **不是幻觉** | 检查检索到的chunks是否包含完整信息 |
| **推理错误** | 基于正确信息但推理逻辑出错 | ❌ **不是幻觉** | 数据来源正确但推理链条有误 |
| **计算错误** | 数值计算错误但数据来源正确 | ❌ **不是幻觉** | 原始数据正确但公式/结果错误 |
| **提取错误** | 从正确位置提取了错误信息 | ❌ **不是幻觉** | 定位正确但读取了错误单元格 |

## 🎯 各类型问题的幻觉检测流程

### 1. 事实提取类

**问题示例**: "中国人保2022年度的营业收入总额是多少亿元？"

**检测流程**:
1. 提取答案中的数值（如"150亿元"）
2. 在源文档中搜索该数值
3. 如果**不存在** → ✅ **幻觉**（数值编造）
4. 如果**存在但位置错误** → ❌ **非幻觉**（提取错误）
5. 如果**未找到相关页面** → ❌ **非幻觉**（检索失败）

**判断标准**:
- ✅ 幻觉: 编造的数值在源文档中完全不存在
- ❌ 非幻觉: 数值存在但提取位置错误/单位错误

### 2. 列举枚举类 ⚠️ 关键区分点

**问题示例**: "请列举中国人保2022年度前五大客户的名称"

**检测流程**:
1. 提取答案中的每个客户名称
2. 对每个名称在源文档中搜索
3. 如果某个名称**不存在** → ✅ **幻觉**（编造名单项）
4. 如果所有名称都存在但**数量不足**（如只列出3个而非5个）→ ❌ **非幻觉**（检索不完整）

**判断标准**:
- ✅ 幻觉: 列表中包含源文档中不存在的项
- ❌ 非幻觉: 列表不完整但所有列出的项都是真实的

**重要**: 列表不完整本身**不是幻觉**，只有编造不存在的项才是幻觉。

### 3. 比较计算类

**问题示例**: "计算中国人保2022年度营业收入同比增长率"

**检测流程**:
1. 提取答案中的原始数据（2022年和2021年的营业收入）
2. 在源文档中验证这些数据是否存在
3. 如果原始数据**不存在** → ✅ **幻觉**（数据编造）
4. 如果原始数据存在但**计算结果错误** → ❌ **非幻觉**（计算错误）
5. 如果原始数据存在但**使用了错误年度的数据** → ❌ **非幻觉**（时间混淆，但数据本身是真实的）

**判断标准**:
- ✅ 幻觉: 编造了源文档中不存在的原始数据
- ❌ 非幻觉: 使用正确的原始数据但计算过程出错

### 4. 判断验证类

**问题示例**: "中国人保2022年度是否实施现金分红？如实施，分红金额是多少？"

**检测流程**:
1. 检查答案是否声称"实施了分红"
2. 在源文档中搜索"分红"、"股利"等关键词
3. 如果**完全未提及**但答案说"实施了" → ✅ **幻觉**（虚构事件）
4. 如果**有提及但答案判断错误**（如说"未实施"但实际实施了）→ ❌ **非幻觉**（判断错误）
5. 如果**有提及但细节提取错误**（如分红金额错误）→ ❌ **非幻觉**（提取错误）

**判断标准**:
- ✅ 幻觉: 编造了源文档中未披露的事件
- ❌ 非幻觉: 事件存在但判断/提取错误

### 5. 推理分析类

**问题示例**: "分析中国人保2022年度营业收入增长的主要驱动因素"

**检测流程**:
1. 提取答案中的归因（如"因为产品价格上涨"）
2. 在源文档的管理层讨论章节中搜索该归因
3. 如果**完全未提及**该归因 → ✅ **幻觉**（编造的因果关系）
4. 如果**有提及但推理逻辑错误**（如数据支持A但模型归因于B）→ ❌ **非幻觉**（推理错误）
5. 如果**有提及但推断过度**（如文档说"可能"但模型说"主要"）→ ❌ **非幻觉**（过度推断）

**判断标准**:
- ✅ 幻觉: 编造了源文档中未提及的因果关系
- ❌ 非幻觉: 基于真实信息但推理逻辑错误

## 🔍 幻觉检测检查清单

### 第一步：信息真实性验证
- [ ] 答案中的每个数值是否在源文档中存在？
- [ ] 答案中的每个名称是否在源文档中出现？
- [ ] 答案中提及的事件是否在源文档中披露？
- [ ] 答案中的因果关系是否在源文档中明确表述？

### 第二步：错误类型判断
如果信息在源文档中**存在**：
- [ ] 答案是否完整？（列举类）
- [ ] 计算是否正确？（计算类）
- [ ] 判断是否准确？（判断类）
- [ ] 推理是否合理？（推理类）

如果信息在源文档中**不存在**：
- [ ] 标记为 ✅ **幻觉**

## 📝 标注示例

### 示例1: 列举枚举类（关键区分）

**问题**: 请列举中国人保2022年度前五大客户的名称

**答案A**: 
```
1. 客户A
2. 客户B  
3. 客户C
```

**验证结果**:
- 客户A、B、C都在源文档中存在
- 但只列出了3个而非5个

**标注**: ❌ **非幻觉错误（检索不完整）**

---

**答案B**:
```
1. 客户A
2. 客户B
3. 客户X（编造的）
4. 客户C
```

**验证结果**:
- 客户A、B、C存在
- 客户X在源文档中不存在

**标注**: ✅ **幻觉（编造名单项）**

### 示例2: 推理分析类

**问题**: 分析营业收入增长的原因

**答案**: "因为产品价格上涨和销量增长"

**验证结果**:
- 在管理层讨论章节中搜索
- 章节中明确提到"产品价格上涨和销量增长"

**标注**: ❌ **非幻觉**（信息真实，但需进一步检查推理是否合理）

---

**答案**: "因为市场扩张和品牌影响力提升"

**验证结果**:
- 在管理层讨论章节中搜索
- 章节中未提及"市场扩张和品牌影响力"作为增长原因

**标注**: ✅ **幻觉（编造的因果关系）**

## 🎯 标注最佳实践

1. **先验证真实性，再判断错误类型**
   - 第一步：信息是否在源文档中存在？
   - 第二步：如果存在，是什么类型的错误？

2. **区分"遗漏"和"编造"**
   - 遗漏 = 检索不完整（非幻觉）
   - 编造 = 信息不存在（幻觉）

3. **区分"计算错误"和"数据编造"**
   - 计算错误 = 数据正确但计算过程出错（非幻觉）
   - 数据编造 = 原始数据不存在（幻觉）

4. **区分"推理错误"和"因果关系编造"**
   - 推理错误 = 基于真实信息但推理逻辑错误（非幻觉）
   - 因果关系编造 = 编造不存在的归因（幻觉）
